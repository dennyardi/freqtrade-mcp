Koneksi Hermes Agent

Copy YAML konfigurasi di bawah, kirim ke chat Hermes di Telegram untuk menghubungkan agent.

Endpoint https://trade.dennyardi.com/mcp
Protocol MCP v2.x / Streamable HTTP
Auth Bearer Token
Enforcement Server-side per token
Bearer Token agentfreqtrade

Token ini memberi akses ke semua 12 tools (read + write). Simpan dengan aman, jangan bagikan ke pihak lain.

ft-mcp-onam14mibilt1b99wkpr
Kirim YAML ke Hermes via Telegram

Copy seluruh blok YAML di bawah, paste dan kirim ke chat agentfreqtrade di Telegram. Hermes akan membaca dan menerapkan konfigurasi MCP secara otomatis.

yaml 
mcp:
  servers:
    freqtrade:
      type: http
      url: https://trade.dennyardi.com/mcp
      headers:
        Authorization: "Bearer ft-mcp-onam14mibilt1b99wkpr"
