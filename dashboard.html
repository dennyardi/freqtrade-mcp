Koneksi Hermes Agent

Copy YAML di bawah lalu kirim langsung ke Hermes via chat Telegram untuk menghubungkan kedua agent.

MCP SSE Endpoint: https://trade.dennyardi.com/sse
Protocol: MCP v2.x over HTTP/SSE  ·  Auth: 2 Bearer Token terpisah — 1 per agent  ·  Enforcement: Server-side per token
🔑

Bearer Token — Agent Pembuat Strategi

Token ini memberi akses ke semua 12 tools (read + write). Khusus untuk agentfreqtrade.

ft-mcp-onam14mibilt1b99wkpr
1

Kirim YAML ini ke Hermes via Telegram

Copy seluruh blok YAML di bawah, lalu paste dan kirim ke chat agentfreqtrade di Telegram. Hermes akan otomatis membaca dan menerapkan konfigurasi MCP.

yaml — paste ke Telegram 
mcp:
  servers:
    freqtrade:
      type: sse
      url: https://trade.dennyardi.com/sse
      headers:
        Authorization: "Bearer ft-mcp-onam14mibilt1b99wkpr"
2

Verifikasi di Telegram

Setelah YAML dikirim, kirim pesan ini ke Hermes untuk memastikan koneksi berhasil:

Telegram → agentfreqtrade 
tampilkan daftar strategi yang tersedia di freqtrade MCP
3

Contoh perintah via Telegram

Setelah terhubung, kamu bisa chat natural ke agentfreqtrade:

Telegram → agentfreqtrade
download data BTC/USDT timeframe 1h untuk 180 hari terakhir

buat strategi RSI crossover + MACD confirmation untuk BTC/USDT

backtest strategi RSIStrategy untuk BTC/USDT
timeframe 1h, periode 1 Januari - 1 Desember 2024

jalankan hyperopt RSIStrategy, 100 epochs,
optimasi roi, stoploss dan trailing

batalkan job abc12345
