Koneksi Hermes Agent

Panduan menghubungkan Hermes Agent via Telegram ke Freqtrade MCP Server ini.

MCP SSE Endpoint: https://trade.dennyardi.com/sse
Protocol: MCP v2.x over HTTP/SSE  ·  Auth: Bearer Token (internal)
🔑

Bearer Token (untuk Hermes config)

Token ini digunakan Hermes Agent untuk autentikasi ke MCP Server. Simpan dengan aman.

ft-mcp-onam14mibilt1b99wkpr
1

Konfigurasi via Hermes CLI / Telegram

Kirim perintah ini ke Hermes di Telegram, atau jalankan via CLI di setiap VPS Hermes:

bash 
hermes config set mcp.servers.freqtrade.type sse
hermes config set mcp.servers.freqtrade.url https://trade.dennyardi.com/sse
hermes config set mcp.servers.freqtrade.headers.Authorization "Bearer ft-mcp-onam14mibilt1b99wkpr"
2

Atau edit config.yaml langsung

Edit ~/.hermes/config.yaml dan tambahkan:

yaml 
mcp:
  servers:
    freqtrade:
      type: sse
      url: https://trade.dennyardi.com/sse
      headers:
        Authorization: "Bearer ft-mcp-onam14mibilt1b99wkpr"
3

Verifikasi koneksi

Restart Hermes, lalu cek tools tersedia:

bash 
hermes tools list | grep freqtrade
4
